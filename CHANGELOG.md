## 0.1.1 — 2026-10-02

### Fixed
- Optional modules no longer auto-enable (`:-yes` defaults removed)
- Abuse IP blocking only when user explicitly answers yes; answering no removes prior SecureBox abuse rules
- UFW / Fail2Ban / IPv6 / unattended / services require explicit yes
- Dangerous prompts default to N
- One-click is conservative unless flags opt in
- Stable install URL via `releases/latest`

### Added
- Local re-run: `sudo mrclock`
- Live server status panel above menu
- `SECUREBOX_REF=latest` auto-resolves newest GitHub Release tag
